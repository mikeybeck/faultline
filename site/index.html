Watch → group → jump

  1. Watch what you already run

    Log files, command stdout such as npm run dev, and browser page errors from an unpacked extension. No script tag in your app.

  2. One row per bug

    Repeats collapse to a single inbox row (×N). Changing IDs and quoted noise are stripped so one bug stays one row.

  3. Open the real line

    Jump to file:line in VS Code, Cursor, PhpStorm, or a custom editor command. Sourcemaps remap generated JavaScript when maps are available.

Download

Desktop app for Linux and Windows (amd64). Pick your OS — then run it and open a project folder. Desktop binaries below are still v0.1.13; the browser extension zip is v0.1.14.

Linux faultline-linux-amd64 chmod +x, then run Windows faultline-windows-amd64.exe Double-click the installer binary, or run from a terminal

macOS desktop build is not available yet. On a Mac you can still run the terminal UI via Go, or watch releases for a native app.

  1. Open Faultline and choose a project folder (or add a log file / command).
  2. When an error appears, use Open in editor to jump to file:line.
